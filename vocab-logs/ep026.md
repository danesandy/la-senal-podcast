# Vocabulario — La antena del techo

## Nuevo

- **el diseño / diseñar** — design / to design
- **barato/barata** — cheap
- **caro/cara** — expensive (circled pair with barato)
- **construir** — to build
- **el prototipo** — prototype, first test model
- **la oreja / el oído** — outer ear / inner ear-hearing (circled pair)
- **multiplicar** — to multiply, grow in number
- **el alquiler** — rent
- **la vergüenza** — shame, embarrassment
- **devolver** — to give back, return something
